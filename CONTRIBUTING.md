# Участие в разработке

[← README](README.md)

Cudy Monitor Pro — независимый проект для экспериментов с ARM64-роутерами и Entware. Особенно полезны тесты совместимости, исправления графиков и улучшения доступности интерфейса.

## Сообщения об ошибках

Используйте [Issue Templates](https://github.com/stub11/cudy-monitor-pro/issues/new/choose) и [руководство тестировщика](docs/TESTING.ru.md). **Не публикуйте** IP/MAC-адреса, SSID, серийные номера, email, токены, пароли, SSH-ключи, конфигурации роутера и полные журналы.

## Разработка

- Rust-код: `cudy-monitor/src/main.rs`.
- Интерфейс: `cudy-monitor/web/index.html` (встроен в бинарник).
- Установка/OTA: `cudy-monitor/scripts/`.
- CI: `.github/workflows/`.
- Лицензия: MIT.

Для разработки желательно иметь Rust stable и Node.js:

```sh
cd cudy-monitor
cargo test --all-targets
cargo build
```

Независимые тесты скриптов и интерфейса выполняются в GitHub Actions. Не запускайте тесты, управляющие службами, на рабочем роутере без отдельной подготовки. Публикация из `main` может запускать ARM64-сборку и выпуск релиза; изменения лучше предлагать через pull request.

При изменении версий согласуйте `Cargo.toml`, changelog и релизные теги; не перезаписывайте существующие релизы. Пишите, на какой модели и версии прошивки **фактически проверяли** изменение, а какие тесты выполнялись только на CI.

Публикуйте в Git только тестовые данные и исходный код без персональных данных, реальных конфигураций и секретов.
