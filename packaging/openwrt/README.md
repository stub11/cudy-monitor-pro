# Native OpenWrt 25.12+ APK v3 (ARM64, mediatek/filogic)

This directory is an OpenWrt SDK package recipe, NOT an Alpine APKBUILD. The official OpenWrt SDK produces the APK v3 package. Do not rename an Entware .ipk or use Alpine's default apk tooling to make an OpenWrt 25.12 package.

The native OpenWrt package:
- installs the standalone static Rust binary at `/usr/bin/cudy-monitor-pro`;
- installs a procd init script, disabled administrative service actions;
- stores its private listen address at `/etc/cudy-monitor-pro/bind` (default 127.0.0.1:8237, restricted on purpose);
- includes `cudy-monitor-lan`, which safely selects the router's LAN IP;
- does not use Entware `opkg`, modify DNS/firewall, or change routing;
- does not yet support native APK-integrated in-panel OTA; use `apk upgrade` for signed repository upgrades and do not apply the Entware binary updater here.

## Clean install (tester, SSH)
1. Verify version and architecture: `cat /etc/openwrt_release; apk --print-arch; uname -m`.
2. Backup config, keep a stable SSH connection, and make sure no Entware monitor is already bound to 8237.
3. Obtain the APK v3 generated by the `openwrt-25.12-apk.yml` workflow from this repository. Its target is mediatek/filogic, OpenWrt 25.12.6.
4. Copy it onto the ROUTER, e.g. `/tmp/cudy-monitor-pro-1.2.2-r1.apk`. Run `apk add --allow-untrusted /tmp/cudy-monitor-pro-1.2.2-r1.apk` for a trusted artifact inspected by the tester. Unsigned APKs do not provide publisher authentication.
5. The daemon starts on loopback only. Run `cudy-monitor-lan --check` and then `cudy-monitor-lan --lan` to expose it to a trusted LAN. If LAN selection is ambiguous, use `cudy-monitor-lan --bind-ip 192.168.1.1` with the *actual private IPv4 assigned to your router*.
6. Visit `http://ROUTER_LAN_IP:8237/`. The panel currently has NO password: never expose the port to WAN, guests or untrusted VLANs.

Native APK and Entware IPK are separate install flavors. **Do not install both simultaneously**, since they use the same port and do not coordinate their service lifecycles. If Entware monitor exists, stop/disable it after backing up settings before starting native package. Do not delete or replace unrelated Entware packages.

Uninstall: `apk del cudy-monitor-pro`. Configuration in /etc/cudy-monitor-pro is intentionally left for manual review/backup.

## Build outline
The GitHub workflow compiles a static `aarch64-unknown-linux-musl` binary, downloads and verifies the official OpenWrt 25.12.6 mediatek/filogic SDK checksum, stages this Makefile and binary in SDK/package/cudy-monitor-pro/files, then runs make package/cudy-monitor-pro/compile with CONFIG_PACKAGE_cudy-monitor-pro=y. The SDK, not the Entware packaging script, creates the APK. Verify `apk info`/package metadata before publishing. Hardware install on Netis N6 v2 is pending.
