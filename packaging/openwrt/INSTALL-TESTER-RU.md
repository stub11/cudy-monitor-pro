# Cudy Monitor Pro — инструкция для тестера Netis N6 v2

**Устройство:** Netis N6 v2, OpenWrt 25.12.6 (mediatek/filogic, ARM64).
**Файл:** [cudy-monitor-pro-1.2.2-r1.apk](https://github.com/stub11/cudy-monitor-pro/releases/download/cudy-monitor-openwrt-v1.2.2/cudy-monitor-pro-1.2.2-r1.apk) — это пакет **OpenWrt APK**, а не Android APK и не Entware IPK.

> Сначала сделайте резервную копию настроек OpenWrt. Подключаться к роутеру следует через SSH. Установка производится на свой риск; реальная проверка на Netis N6 v2 продолжается. Не устанавливайте одновременно версии Entware и OpenWrt: они используют один порт 8237. По умолчанию панель не защищена паролем — не открывайте её в интернет.

## 1. Скачать APK на роутер

В SSH-консоли OpenWrt выполните:

```sh
cd /tmp
wget -O cudy-monitor-pro-1.2.2-r1.apk 'https://github.com/stub11/cudy-monitor-pro/releases/download/cudy-monitor-openwrt-v1.2.2/cudy-monitor-pro-1.2.2-r1.apk'
```

Если файл уже скачан на телефон/ПК, можно вместо wget передать его на роутер в `/tmp` по SCP/SFTP.

## 2. Проверить файл

```sh
cd /tmp
echo 'b946fbf9c8b7fca85f02bfe89fffb215782226731dd6f0044070669d864175b5  cudy-monitor-pro-1.2.2-r1.apk' | sha256sum -c -
```

Должно появиться `cudy-monitor-pro-1.2.2-r1.apk: OK`. При другой сумме **не устанавливать**.

## 3. Установить

```sh
apk add --allow-untrusted /tmp/cudy-monitor-pro-1.2.2-r1.apk
```

Если пакет уже установлен, сначала сообщите об этом автору; не смешивайте с Entware IPK. Опция `--allow-untrusted` нужна, потому что этот экспериментальный пакет не подписан ключом доверенного репозитория. Используйте только проверенный файл релиза.

## 4. Разрешить открытие панели из домашней сети — ОБЯЗАТЕЛЬНО

```sh
cudy-monitor-lan --lan
```

После успеха появится строка вида:

```text
Monitor: http://192.168.1.1:8237/
```

**Это адрес панели!** Откройте его в Chrome/другом браузере **на устройстве, подключённом к LAN/Wi-Fi этого роутера**. НЕ вводите URL в SSH-терминал, не открывайте APK на Android и не используйте стандартную страницу LuCI.

Если выводит ошибку о нескольких LAN-адресах, сначала узнайте IP роутера:

```sh
ip -4 addr show
```

Если его LAN действительно `192.168.1.1`, выполните:

```sh
cudy-monitor-lan --bind-ip 192.168.1.1
```

Не используйте `192.168.1.1`, если у вашего роутера другой адрес. Команда не меняет адрес самого роутера.

## 5. Проверить, что панель работает

```sh
/etc/init.d/cudy-monitor-pro status
```

**После `--lan` сервис слушает LAN-IP, а не `127.0.0.1`.** Для проверки HTTP используйте адрес из строки `Monitor:`, например:

```sh
wget -qO- http://192.168.1.1:8237/health
```

Если не открывается: пришлите вывод команд `cat /etc/cudy-monitor-pro/bind`, `/etc/init.d/cudy-monitor-pro status`, `ip -4 addr show`, `logread | grep -i cudy`. Не публикуйте внешние IP, пароли и токены.

## Что делать после установки

Проверьте страницы «Обзор», «Процессы», «Сервисы», «Сеть», «Хранилище», «Журналы», «Настройки» на компьютере и телефоне. Пришлите скриншот, версии OpenWrt и монитора и описание неработающих показателей.

**Не нужно** ставить Entware curl, запускать старый `/opt/tmp/cudy-monitor-install.sh` или перепрошивать роутер. Этот пакет — нативный для OpenWrt.
