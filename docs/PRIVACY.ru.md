# Конфиденциальность и обработка данных

[← README](../README.md)

**Cudy Monitor Pro работает локально.** Веб-панель загружается из исполняемого файла на роутере и опрашивает его локальные HTTP-эндпоинты. Для работы основной панели не нужен аккаунт у автора, сторонний CDN или внешний сервер телеметрии.

## Что читает монитор

- Системные метрики (CPU, память, процессы, время работы).
- Показания доступных датчиков и состояние накопителя с Entware.
- Счётчики сетевых интерфейсов и локальные статусы дополнительных служб.

Эта информация **может быть чувствительной**, например имена процессов, локальные сетевые адреса и характеристики ваших устройств. Поэтому панель по умолчанию доступна лишь с `127.0.0.1`, а на доверенную LAN выводится только по вашему решению.

## Что хранится

Графики и события монитора сохраняются **в оперативной памяти** и исчезают при перезапуске программы. Установочные скрипты сохраняют свои файлы и параметры работы в `/opt`, включая выбранный адрес прослушивания и резервный бинарник для отката.

Монитор не загружает диагностические отчёты автоматически на GitHub. Автор проекта не получает ваши системные метрики просто потому, что вы установили монитор.

## Сеть и GitHub

При ручной проверке/установке обновления установочный или OTA-скрипт обращается к **GitHub Releases** для скачивания манифеста и файлов. GitHub может обрабатывать запросы по своим правилам, в том числе сетевые метаданные отправителя. Это не является встроенной телеметрией Cudy Monitor Pro.

## Важное ограничение

**Веб-интерфейс не защищён логином.** Не публикуйте порт `8237` в интернете, не открывайте его на недоверенной сети и не пробрасывайте через общедоступный туннель без отдельной защищённой авторизации. Проверка Origin не заменяет аутентификацию.

## Если вы создаёте Issue

Всё, что размещено в публичном GitHub Issue, становится общедоступным. Рекомендуется использовать только обезличенные данные и скриншоты. Инструкции — в [TESTING.ru.md](TESTING.ru.md). Не отправляйте реальные секреты, сырые дампы и конфигурацию роутера.

Этот документ описывает возможности конкретного опубликованного исходного кода; поведение сторонних прошивок, браузеров, провайдера и платформы GitHub не контролируется проектом.
