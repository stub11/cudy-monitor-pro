# Перенос проверенных подходов CM Aurora в Cudy Monitor Pro — 1.2.4

Дата: 2026-11-10. Источник: локальный проект CM Aurora, `D:\AI\projects\CM\source`, а также `FEATURE_MATRIX.md` и документы `V0_1_115_CONNECTION_FRESHNESS.md`, `V0_1_119_HOME_METRIC_TRENDS.md`. CM Aurora и Cudy Monitor Pro остаются независимыми проектами; Android/Kotlin-код и конфиденциальные данные в публичный репозиторий не переносились.

## Перенесённые принципы

1. **Свежесть данных и разрыв связи.** Как в CM Aurora, отображение должно явно отличать последний успешный замер от отсутствия связи. Теперь после ошибки API экран получает класс `telemetry-stale`; прежние KPI визуально приглушаются, сетевой график не выдаётся за живые данные, а статус показывает потерю связи. После успешного ответа обычное оформление возвращается. Сохранение предыдущих значений оставлено намеренно, но с пометкой «могут быть устаревшими».
2. **Никаких вымышленных данных.** Расчёт RAM и статусы получаются только из реального `/proc/meminfo`. При отсутствии полей новое значение не подменяется нулём: оно сериализуется в JSON как `null` и UI пишет «недостаточно данных».
3. **Прозрачность памяти.** В ответ API добавлены `mem_htop_used` и `mem_available`, в МиБ. Основные исторические поля `mem_total`, `mem_used` и `mem_cached` сохраняют прежнюю семантику для совместимости: `mem_used = MemTotal − MemAvailable`. Дополнительное «Без кэша (≈htop)» использует `MemTotal − MemFree − Buffers − Cached − SReclaimable + Shmem`, с защитой от переполнения/неполных данных. Новый показатель является приближением к htop, поскольку настройки и версии htop могут отличаться.
4. **Стабильная верстка.** Для дополнительной строки RAM задана минимальная высота, чтобы обновления не меняли размеры карточки.

## Проверки

- Добавлены unit-тесты формул на фактической ранее представленной фикстуре Netis N6 v2 (`MemTotal=239564 KiB`, `MemAvailable=73540 KiB`, `htop-like=111316 KiB`) и на некорректно малом наборе данных.
- CI: smoke-проверка новых полей JSON, наличие нового RAM-элемента и статуса stale.
- Требуются CI-сборка и физическая проверка версии 1.2.4, особенно после обновления и на Keenetic Ported.
