## Что подтверждено

- Физический Cudy с Keenetic Ported + Entware, штатная версия 1.2.27. 299 из 299 запросов за 601 секунду, максимальный ответ 274 мс. Проверены восемь разделов, фильтр процессов, история WAN, показания CPU и двух радиомодулей.
- ARM64-кандидат из PR запущен на том же Cudy отдельно в режиме чтения. Средняя нагрузка 1/5/15 минут и отдельные серии CPU и Wi-Fi получены из реальных датчиков. Временный процесс остановлен и каталог удалён.
- Штатная проверка обновлений обнаружила одинаковую установленную, запущенную и доступную версию 1.2.27. Изолированный Entware apply отверг неверный SHA-256, затем активировал ARM64-кандидат. Сбой проверки здоровья вызвал восстановление настоящего ARM64-релиза 1.2.25. Проверены файл и восстановленный процесс. Штатная панель оставалась доступной.
- GitHub Actions завершил Rust-регрессии, проверки Chromium/WebKit, ARM64 и тестовую упаковку OpenWrt MIPSEL. [Entware и Rust](https://github.com/stub11/cudy-monitor-pro/actions/runs/45799450475) · [Браузеры](https://github.com/stub11/cudy-monitor-pro/actions/runs/45799450517) · [MIPSEL](https://github.com/stub11/cudy-monitor-pro/actions/runs/45799450438).

## Как продолжить без ПК

1. Продолжайте работу от ветки PR #153. Не переносите старые локальные коммиты поверх актуальной версии автоматически. Если срок действия артефакта истёк, пересоберите его из нужного коммита через GitHub Actions.
2. Команды для Linux: `cargo test --manifest-path cudy-monitor/Cargo.toml`, `python3 -B -m unittest discover -s scripts/tests` и `python3 -B scripts/public_release_guard.py`. Браузерные интеграции описаны в [workflow](../.github/workflows/browser-compatibility.yml).
3. Штатное OTA остаётся открытым до появления более новой проверенной стабильной версии. Для Netis N6 применяйте [протокол MIPSEL](OPENWRT-MIPSEL-QA-RU.md). Частичный отчёт с Netis относится к предыдущему тестовому APK. Точный ABI, хеш установленного пакета, перезапуск и длительная проверка текущей сборки открыты. MIPSEL OTA остаётся заблокирован.
4. Визуальная доводка отложена. Размеры, SHA-256 и описание оригинального макета указаны в [спецификации](APPROVED-UI-SPEC.md). Исходный PNG ещё требуется найти и проверить.
