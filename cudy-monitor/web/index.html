«Установлен» означает наличие KeenKit, а не запущенный процесс. Для D2K доступно включение, выключение и перезапуск; для DoQ — включение, перезапуск и временная пауза на 90 секунд с автоматическим восстановлением. Управление по умолчанию отключено на сервере, поскольку доступ к панели не требует токена. Действия могут временно нарушить работу DNS.

OpenWrt · обновление через APK
Эта версия установлена нативным пакетом OpenWrt. Доступно обновление прямо из панели. Будет установлен только проверенный официальный APK с SHA-256 и резервной копией для отката. При выключенной авторизации любой пользователь доверенной LAN может запустить обновление. Для дополнительной защиты включите авторизацию в настройках.
wget -qO /tmp/cudy-monitor-easy.sh https://raw.githubusercontent.com/stub11/cudy-monitor-pro/main/scripts/easy-install.sh && sh /tmp/cudy-monitor-easy.sh --update
 Проверить версии на GitHub
Нажмите «Проверить обновления».
 
После установки панель кратковременно отключится и запустится заново. Без установленного компонента обновлений кнопка будет недоступна.
