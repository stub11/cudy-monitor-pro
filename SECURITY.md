# Security and disclosure
Do not place passwords, access tokens, router backups, SSH private keys, hostnames, residential WAN IPs, private LAN topology, or personal emails in issues or repository files. Redact screenshots and logs before reporting bugs.

The monitor is intended for a trusted LAN only and provides no login gate. Service controls are opt-in and should remain off unless the network is isolated.

For sensitive reports, use GitHub private vulnerability reporting if enabled or contact the repository owner through GitHub without posting secrets in public issues.
